這週 AI 圈最值得看的價格新聞，其實不是 Gemini 4 Carbon 每百萬 token 2 美元這個數字。

更值得看的是 Amazon，也就是 Anthropic 最大的金主，把自家內部工單系統裡的 Claude Sonnet 4.6 換掉了。換上的是一個**連一句話都寫不出來**的小型「決策模型」，成本直接少了 98%。

前沿模型確實在打價格戰。但更大的變化是，有一大塊企業 AI 工作量正在離開這個戰場。

## 先看帳面數字

Google 11 月 10 日全面開放 Gemini 4 Carbon，推廣價是**每百萬輸入 token 2 美元、輸出 token 10 美元**。根據 The Verge 的整理，這大約是 OpenAI GPT-6 Astra 的五分之一，也只有前一天剛發表的 Anthropic Fable 5.2 的四分之一。就算 11 月 30 日推廣期結束、價格翻倍到 **4／20 美元**，Carbon 的單位 token 價格還是明顯低於其他前沿模型。

更有意思的是 Google 這次主打的評測。它跟 Artificial Analysis 合作，推出新的「多模態知識代理（MKA）」基準，涵蓋 200 個代理式任務。Carbon 拿下第一，而且**用的 token 只有第二名的三分之一**。一家模型公司會特地設計一個獎勵「省 token」的評測，代表客戶現在第一個問的已經是成本。

拉長時間看就知道降價有多快。2023 年 3 月 GPT-4 上市時，每百萬 token 是輸入 30 美元、輸出 60 美元。三年半後，Google 號稱「史上最強」的模型，輸入價只剩當年的十五分之一。2025 年 1 月 DeepSeek R1 出來之後，接近前沿的推理能力就被打到個位數美元，從那時起，每家廠商都得解釋自己憑什麼收比較貴。

這個劇本台灣人應該很熟。2019 年電信三雄打 499 吃到飽，表面上在比誰便宜，實際上在搶用戶黏著度，等用戶綁約之後再慢慢調整。Carbon 的推廣價只維持三週，邏輯差不多。

## 每 token 單價，其實是個誤導指標

Google 的發表內容裡有一句話被很多報導帶過：單位 token 比較便宜，**不代表完成任務比較便宜**，因為不同模型處理同一件事用的 token 數量可能差很多。

這句話才是重點。各家的輸出 token 通常比輸入貴 3 到 5 倍，而推理型模型輸出的很大一部分是它「邊想邊講」的過程，這些全部算在你的帳上。Dev.to 上有位工程師舉了個例子：把 50 則客訴分類，用表格輸出大約 500 個 token 就夠了；但如果沒指定格式，模型會每則寫一段理由，最後再加總結，整份變成 2,500 個 token。結果一樣，輸出成本是五倍。

套到選模型上：單價便宜一半、但想得比別人久一倍的模型，實際成本一樣，速度還更慢。單價貴四倍、但只用三分之一 token 就做完的模型，反而有機會划算。所以現在真正該比的是**每完成一個任務花多少錢**，這也是 Google 要把「第一名」跟「省三倍 token」放在一起講的原因。

我的判斷是：一年內，每百萬 token 的牌價會變得跟 CPU 時脈差不多，看起來很專業、也能互相比較，但對決策的參考價值愈來愈低。

## 沒人在講的事：Google 叫你別買它最強的模型

仔細看 Google 的產品定位。官方說法是：**對大多數軟體工程和知識工作來說，Argon 才是「理想選擇」**。Gemini App 的模型選單裡，Argon 標的是「程式與分析」，Carbon 標的是「最複雜的工作」。

一家前沿 AI 公司發表旗艦模型的同時，直接告訴大部分客戶不需要用它。這不是謙虛，而是反映了現實：最頂級的模型已經變成專科醫生，只處理最難的那 5%，不再是預設選項。

Antigravity 平台新推的 `/swarm` 功能把這件事講得更清楚。Google 建議的配置是讓 Carbon 負責架構設計、協調、稽核這類需要最深推理的角色，其他平行執行的工作交給「更快、更輕量的模型」。換成台灣科技業的說法，Carbon 是 PM 兼 code reviewer，真正寫 code 的是一群便宜的工程師。

所以 Carbon、Fable 5.2 和 Meta 的 Muse Ember 搶的其實是每條工作流程中最難的那一段，而大部分的量正流向「夠用就好、愈便宜愈好」的模型。

## 把 Amazon 這個案例讀仔細

Strands Decider 這篇工程文章，比任何發表會上的跑分圖都值得企業 IT 主管讀一遍。

Amazon 和 AWS 團隊原本用 Sonnet 4.6 幫內部工單貼標籤，類型包括客戶升級、容量申請、自動告警、資安發現等，總共 20 個類別。每張工單都要跑一段很長的系統提示，讓模型輸出 JSON 再附上推理過程。這個做法很合理，也是 2025 年大部分企業的標準架構。

後來兩位工程師換上了 Strands Decider。這種模型不生成文字，你給它狀態和選項，它回傳每個選項的機率加上一個信心分數。他們先試 2B 版本，再換成基於 Gemma 4 的 E4B 版本，調整信心門檻之後，**在另一組測試工單上的表現超過了正式環境裡的 Sonnet**。硬體只要一張 A10G（SageMaker `ml.g5.xlarge`），記憶體用量約 19 GiB，單次推論約 640 毫秒，Amazon 估計一年可以省下數百萬美元。

我看到三個重點：

1. **這個任務從頭到尾就不需要生成文字。**分類問題被硬塞給文字生成模型，只是因為當時手上只有這個工具。每一次「請用 JSON 說明你的推理」，都是在為一道選擇題付作文的錢。
2. **遷移路徑一點都不炫。**SQS、Lambda、SageMaker、AppConfig、CloudWatch、CDK，再加一個三段式開關（`BEDROCK`／`DUAL`／新模型），讓新舊模型並行比對之後再切換。任何像樣的平台團隊一季內就能照做。
3. **注意是誰發的文。**這篇文章出現在 AWS 自己的 Strands 部落格上。AWS 一邊在 Bedrock 上賣 Claude，一邊公開教客戶怎麼在特定場景不用付錢給 Claude。雲端廠商的利益是賣 GPU 時數和自家模型，不是幫合作夥伴賣 token。

對台灣企業來說，這個案例特別有參考價值。電商客服分流、銀行的客訴分類、製造業的異常工單派送，有很多 SI 廠商這兩年包裝成「GenAI 專案」，底層其實就是分類問題，卻按前沿模型的 token 價在付費。下一輪預算審查時，財務長應該會問：我們的 LLM 用量裡，有多少其實是選擇題？

## 反方論點

最有力的反駁是傑文斯悖論：token 變便宜，總用量反而暴增。`/swarm` 這種代理群會讓 token 用量隨代理數量倍增，對抗式驗證會重跑每一次修改，長時程任務一跑就是好幾個小時。單價降了九成，前沿模型的總營收照樣可能上升，因為每百萬 token 30 美元時沒人敢跑的工作，到了 4 美元就變成日常。

這個論點大致成立，但它忽略了市場結構的變化。前沿模型的需求會在高難度推理這一塊成長，同時在高頻、低複雜度這一塊萎縮，而後者一直是默默撐起營收的那一塊。營收大多來自企業拿 Sonnet 等級模型做重複性雜事的廠商，受到的衝擊最大。

第二個反方觀點：推廣價就是拿來搶客戶的。Carbon 三週後就漲一倍；Google 開放一萬名科學家免費用六個月，看起來也很像在收集訓練資料。Google 並沒有承諾長期低價，它是在用 Anthropic 沒有的現金部位買市佔。

## 值得關注

- **12 月 1 日是 Carbon 的真正考驗。**價格翻倍到 4／20 美元之後，我預測 Google 會延長推廣期或下調 Argon 的價格，而不是讓自己跟 Fable 5.2 的價差縮小。這場價格戰裡，Google 不會先退讓。
- **「每任務 token 數」會變成標準揭露項目。**2027 年年中前，Google、Anthropic、OpenAI 三家至少會有兩家在模型卡上公開效率指標（每任務 token 數或成本），而不只是準確率。MKA 就是範本。
- **Anthropic 的回應會出現在低階市場，而不是高階市場。**Fable 5.2 不用降價也能在高難度任務上贏。但 Anthropic 半年內必須對「Sonnet 拿來做分類太貴」提出明確的解法，不管是更便宜的方案還是結構化輸出產品。不然 Amazon 的案例會在 Bedrock 客戶之間一再重演。
- **決策模型會變成獨立的產品類別。**2027 年第二季前，至少還會有一家大型雲端廠商推出非生成式的決策／分類模型系列並提供託管服務。Strands Decider 是這個新類別的第一代產品，不是單一案例。
- **台灣企業的採購問題會換一個問法**：從「哪個模型最聰明」變成「我們有哪些任務真的需要前沿模型」。先盤點清楚的公司，AI 帳單砍一半以上不是難事；沒盤點的公司，會繼續用前沿模型的價格做分類這種雜事。
