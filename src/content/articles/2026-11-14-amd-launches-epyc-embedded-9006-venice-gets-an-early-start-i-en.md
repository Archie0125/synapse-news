AMD launching embedded Venice alongside its flagship server chips shows embedded customers are no longer an afterthought for AMD's server roadmap.

## Key points

- AMD launched EPYC Embedded 9006 at the same time as its commercial EPYC 9006 'Venice' server CPUs, a first for the embedded line.
- Venice is AMD's first Zen 6 chip family, and servers are now the first products to get the new architecture instead of among the last.
- The SP7 platform increases core counts, energy efficiency, I/O bandwidth and memory bandwidth, and AMD's embedded EPYC portfolio now reaches up to 256 cores.
- Embedded parts go through extra validation for long-life foundational roles, so launching them on day one shortens the usual wait for those customers.
- AMD is betting that embedded customers need the extra compute just as much as cloud and AI buyers do.

## Why it matters

When the 'boring' embedded chip launches on day one next to the flagship, server CPUs have become AMD's top priority, and embedded customers are getting flagship timing for the first time.
